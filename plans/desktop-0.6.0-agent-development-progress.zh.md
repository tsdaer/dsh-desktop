## 已确认的当前事实

### 上游范围

- Chat 渲染、虚拟化、历史分页、SessionPersistence 和存储后端已有上游开发路径。
- 0.6.0 桌面计划不修改这些范围，不增加对应设置、迁移或性能门。
- 上游变更不建立桌面专项任务、指标或发布阻塞项；普通 release smoke 若发现缺陷，则反馈到上游路径。

### Updater

- `DesktopUpdater.ts` 自动检查只有一次 10 秒请求，没有自动退避、代理设置或恢复触发。
- 当前错误类型基于字符串；代理 HTML/网关正文可能被误判为清单错误。
- Tauri updater 已提供 request proxy/timeout，Rust builder 还提供 no-proxy 与 client 配置；无需替换签名更新机制。

### Feature controls

- Bridge 设置当前固定四项，缺少可扩展 feature policy。
- Worktree 入口、Workspace tab、原生文件预览和源代码管理目前无独立开关。
- 原生预览失败已有内嵌 fallback，可作为关闭原生预览时的目标行为。

### Startup diagnostics

- 0.5.7 已把运行时 stdout/stderr 写入 `%TEMP%/dsh-desktop-splash.log`，但启动页只收到通用 readiness 失败。
- 已复现旧版 `dshmarket` 导入已移除设置接口导致插件树退出；stderr 能确认 `dsh-market`/`dshmarket`，页面不能显示或复制该根因。
- 重试按钮可以在 supervisor 尚为 `Running` 时再次进入启动流程；0.6.0 需要把重试绑定到终止与 join 完成。
